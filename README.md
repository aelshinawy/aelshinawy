## Selected projects

### [Gournal](https://github.com/aelshinawy/gournal)

Your work, remembered. A local-first work journal for people and AI agents. Log what you did, and Gournal turns it into searchable history, standups, and work logs. It links entries to your pull requests, commits, and reviews, and an MCP server lets agents such as Claude Code keep the journal up to date for you.

TypeScript · Node.js · SQLite · MCP · [gournal.aelshinawy.com](https://gournal.aelshinawy.com/) · [npm](https://www.npmjs.com/package/gournal)

<a href="https://github.com/aelshinawy/gournal"><img src="https://raw.githubusercontent.com/aelshinawy/gournal/main/demo.gif" alt="Gournal terminal demo" width="640"></a>

### [Multi-tenant Dashboard](https://github.com/aelshinawy/multi-tenant-dashboard)

A multi-tenant analytics dashboard where PostgreSQL Row-Level Security enforces tenant isolation in the database, not only in the app. Tenants are provisioned by a script or an edge function, and a scheduled sync job pulls data incrementally with a cursor and idempotent upserts, then reports its health in the UI.

TypeScript · React · PostgreSQL · Supabase

### [Productick](https://github.com/aelshinawy/productick)

A Pomodoro timer whose engine is a single RxJS stream: a one-second tick merged with user intents and folded through a pure reducer. Jotai persists settings and daily stats, and it works offline as a PWA.

TypeScript · React · RxJS · Jotai
